# Decision records

A decision belongs here only when it is hard to reverse, surprising without context, and the result of a real trade-off: all three. Read the relevant record before changing something that looks wrong on purpose.

Each record is `NNNN-short-slug.md`: a title, then one to three sentences in the present tense saying what is decided and why, in `GLOSSARY.md`'s terms, with optional **Considered** and **Consequences** lines.

A superseded record is deleted and its replacement written; git keeps the history. Agents propose records in a pull request; the maintainer accepts them.
